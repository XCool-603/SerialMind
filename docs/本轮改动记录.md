## 一、CSV 文件导入

**之前**：只能在文本框里手贴 CSV 文本。

**现在**：
- 数据驱动页新增「**选择 CSV 文件**」按钮
- 文本框支持**直接拖入 .csv 文件**
- 自动处理编码：UTF-8 / UTF-8 BOM / 中文 Excel 导出的 **GBK**（乱码时自动按 GBK 重读）
- 载入后**立即保存到用例**，并弹窗告知「文件名 · N 行数据」
- 断言页「绑定 CSV」卡片改为真实状态：未绑定 / 已绑定 N 行，点击跳转

**验证**（`scripts/test-newfeat.mjs`）：
```
✓ 有「选择 CSV 文件」按钮
✓ 文件内容已填入编辑框
✓ 行数统计为 2
✓ 断言页显示已绑定 + 行数
```

## 二、报告趋势

**之前**：报告只有逐条记录，没有趋势、没有汇总。

**现在**：报告页新增「**趋势**」面板：
- 最近 30 次运行的**柱状图**（柱高 = 耗时，绿 = 通过，红 = 失败）
- **近 10 次通过率**
- **平均响应 / 最大响应**（无压测数据时显示 `—`，不假装 0ms）
- **累计发送帧数**

**验证**：
```
✓ 报告页有「趋势」面板
✓ 显示近 10 次通过率
✓ 显示平均响应
✓ 显示累计发送
✓ 有趋势柱状图
```

## 三、AI 远程模型配置

**之前**：有「模型设置」但没有验证手段，用户不知道 Key 对不对。

**现在**：
- 模型设置保留 Base URL / API Key / 模型三项
- 新增「**测试连接**」按钮：发一条最小请求（`max_tokens:1`）
  - 成功 → 绿色 `连通 · deepseek-chat · 420ms`
  - 失败 → 红色 `HTTP 401：...` 或 `网络错误：...`
- 新增「**保存配置**」按钮，显式落盘到 localStorage
- 连通成功后自动保存

**验证**：
```
✓ 模型设置有三项
✓ 有「测试连接」按钮
✓ 没填 Key 时给出提示「还没填 API Key」
```

## 四、无限循环自动停止

**之前**：`repeat=0` 无限循环必须手点停止，忘了就一直跑。

**现在**：用例设置新增两项：
- **最长运行**（秒）：到点自动停，报告里写明「达到最长运行时长 Ns，已自动停止」；0 = 不限
- **失败即停**（开关，默认开）：关掉后某步失败仍跑完剩余轮次，最后整体判失败

**引擎改动**（`src/engine/runner.ts`）：
- 每轮 / 每步前检查 deadline，超时立即退出
- `stopOnFail=false` 时不再提前中断，但保留 `failed` 标记
- 超时不是失败，只是停止，原因单独写进 `reason`

**验证**（`scripts/test-autostop.ts`，11/11）：
```
[1] 无限循环 + 最长运行时长 → 到点自动停
  ✓ 在 1.6s 内自己停了（没跑飞）
  ✓ 用时接近设定值（0.7s~1.6s）
  ✓ reason 说明是超时自动停
  ✓ 跑过的轮次 > 3
[2] maxDurationMs = 0 → 不自动停，按 repeat 收尾
[3] stopOnFail = true（默认）→ 第一次失败就停
[4] stopOnFail = false → 失败也跑完，最后整体判失败
```

## 五、顺带修掉的假 UI（用例页「断言」页签）

原来三张卡片全是写死的假数据：

| 卡片 | 之前 | 现在 |
|---|---|---|
| 断言类型覆盖 | 硬编码「2 处 / 未使用」 | 从真实步骤统计（equals / range / 整帧 / assertNo / set / 流程） |
| 绑定 CSV | 永远「未绑定」 | 显示真实绑定状态与行数，点击跳转 |
| 运行设置 | 假开关、假「1 次」 | 显示真实 失败即停 / 重复次数 / 最长运行 |

页脚「绑定角色」也改成了「标签」（角色已删）。
