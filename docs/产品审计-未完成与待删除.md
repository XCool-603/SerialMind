## 二、半成品（有入口、没闭环）

| # | 功能 | 现状 | 缺口 |
|---|---|---|---|
| 1 | **串口参数** | 写死 `8N1 / 无流控`（`serial.ts` + `lib.rs`） | 数据位/停止位/校验/流控全不可选。**7E1 设备直接不能用** |
| 2 | **用例变量（得分+1）** | 引擎已支持 `vars`（init + step × 轮次） | **UI 没渲染出来**，用户填不了 |
| 3 | **心跳常驻** | 只有「重复次数」上限 99999 | 不能无限跑，跑完就停 |
| 4 | **压测统计** | 只有通过/失败 | 无丢帧率、平均响应、最大延迟 |
| 5 | **数据驱动** | 只能手贴 CSV 文本 | 不能导入 .csv 文件 |
| 6 | **字段类型** | 类型下拉 15 种 | 实际编解码只覆盖 uint/int/float/bool/bitfield/bcd/enum/string/crc；**array / tlv / nested / reserved / timestamp 走兜底当整数** |
| 7 | **AI 草稿** | 面板能用（本地抽取 + 远程调用） | 远程 AI 的 API Key / BaseURL **没有配置入口** |
| 8 | **报告** | 单次结果、导出 HTML/JUnit | 无趋势（连续多轮通过率）、无统计汇总 |
| 9 | **角色（roleId）** | 能建能绑 | **引擎完全不读**，站号不参与组包（纯标签） |
