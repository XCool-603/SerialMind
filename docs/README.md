# SerialMind

> **一个能自己跑起来的 SScom。** 协议和用例配一次，之后每次改完固件点"跑一遍"，它告诉你哪条没过、字节差在哪。
>
> 跨平台（Windows / macOS / Linux）· 硬件无关 · 以自动化测试为唯一目标

## 文档

**唯一有效文档：[SerialMind-V1.0-定稿.md](./SerialMind-V1.0-定稿.md)**

它合并并取代了 V0.1 ~ V0.6 全部增量卡，已删除作废内容。之后所有变更都在定稿上做增量。

历史增量卡在 [`_archive/`](./_archive/)，仅供追溯，**不要照着它实现**。

## 一页看懂

| 维度 | 结论 |
|---|---|
| 定位 | SScom 的超集，比 SScom 更窄：不用看、不用发，跑完给结论 |
| 硬件 | **完全无关**。只认"链路 = 一个串口 + 一串字节"，对面是什么只写在备注里 |
| 层级 | 租户 → **产品（主）** → 链路（辅）/ 协议 / 规则 / 用例 → 套件 |
| 多链路 | 一个产品可以有多个链路，同时打开互不干扰 |
| 产品关系 | 产品之间不复用协议；要复用就复制 |
| 部署 | **本地优先**：无账号、无云端、无网络依赖；云端待定但字段已预留 |
| 产品本体 | **测试引擎**：用例 = 步骤 + 断言；数据驱动；失败现场；回归 diff；CI |
| AI | **草稿助手，不是控制中心**：产出草稿 → 人确认才生效；可完全关闭 |
| 工期 | 单人 21~23 周；双人约 13~15 周 |

## 已确认决策

| # | 决策 |
|---|---|
| 1 | 定位：SScom 超集，目标是自动化测试 |
| 2 | 硬件无关，只认链路（串口 + 字节） |
| 3 | 产品为主、链路为辅；客户 = 租户（本地固定 `local`） |
| 4 | 产品之间不复用协议，复用即复制 |
| 5 | 一个产品可以有多个链路 |
| 6 | 高地位/字节序用户自己调（ABCD / BADC / CDAB / DCBA） |
| 7 | 联动是调试时主动触发（用例主动驱动） |
| 8 | 每条链路、每个报文都支持自动发：心跳、周期、条件、自动应答、超时重发 |
| 9 | AI 只辅助生成草稿，不是主控；可完全关闭 |
| 10 | 本地优先，云端待定；UUIDv7 / tenant_id / rev / UTC / Repository 现在就留好 |

## 同步命令

Calicat 上改了定稿后，拉回仓库：

```powershell
powershell -File ./scripts/sync-calicat-docs.ps1
```

新增卡片后，在 `scripts/sync-calicat-docs.ps1` 的 `$cards` 表里登记 `prd_id -> Dir + Out`。约定：**只有定稿放 `docs/` 根目录，历史卡一律进 `_archive`。**

> ⚠️ 脚本必须保存为 **UTF-8 with BOM**。本机只有 Windows PowerShell 5.1，无 BOM 时会按 ANSI 解析中文导致语法错误。用编辑工具改完脚本后需重新加 BOM。
