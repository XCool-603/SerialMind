## 五、真实可用的操作路径

```
建产品 → 建子产品（PLC 模板）
   ↓
协议页：确认/修改帧结构 → 调试发送面板试发
   ↓
顶栏：选串口 + 参数（8N1/7E1…）→ 连接
   ↓
测试页：一键生成示例用例 → 改步骤/设变量/设循环
   ↓
运行 → 报告页看结果 → 导出日志/HTML
```

这条路径**每一环都有测试覆盖**，可以放心用。

## 七、一句话总结

**主干能用，边缘有假货。**

- 协议 → 发送 → 测试 → 报告：**通**
- 串口参数、变量自增、循环、压测统计、日志导出、帮助：**都是真的**
- 但有 **5 个字段类型选项是假的**、**规则页签是死的**、**用例标签没法编辑导致套件筛选失效**

把上面「删」的 4 项做掉，界面里就不再有假东西了。
